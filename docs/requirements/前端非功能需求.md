# 前端非功能需求

## 1. 目的

本文档定义 `mom-web` 在性能、安全、可靠性、可访问性、可维护性和诊断方面的最低要求。

## 2. 性能

| 编号 | 要求 |
|---|---|
| WEB-NFR-PERF-001 | 生产构建必须按应用独立生成产物，避免无关门户代码进入同一包。 |
| WEB-NFR-PERF-002 | 路由级页面应支持按需加载。 |
| WEB-NFR-PERF-003 | 大列表、谱系图和复杂详情应避免一次加载无界数据。 |
| WEB-NFR-PERF-004 | 页面筛选、分页和导出必须由后端契约支持，不在浏览器加载全量事实数据后处理。 |
| WEB-NFR-PERF-005 | 首屏和关键交互性能指标应进入后续自动化观测。 |

## 3. 安全

| 编号 | 要求 |
|---|---|
| WEB-NFR-SEC-001 | 浏览器只访问 MOM Gateway，不持有内部微服务地址。 |
| WEB-NFR-SEC-002 | Web 登录采用 Authorization Code + PKCE。 |
| WEB-NFR-SEC-003 | Token、刷新、登出和会话失效行为由统一 Access 层管理。 |
| WEB-NFR-SEC-004 | 不在日志、错误提示和持久化状态中暴露 Token、密钥和敏感个人信息。 |
| WEB-NFR-SEC-005 | 前端菜单、路由和按钮控制不能替代服务端授权。 |
| WEB-NFR-SEC-006 | 文件下载必须通过授权接口和短时访问机制。 |
| WEB-NFR-SEC-007 | 用户输入、文件名和服务端消息必须安全渲染，禁止无审查 HTML 注入。 |

## 4. 可靠性与恢复

| 编号 | 要求 |
|---|---|
| WEB-NFR-REL-001 | 页面刷新后应能恢复必要的路由和会话状态。 |
| WEB-NFR-REL-002 | 命令提交必须使用幂等键或服务端提供的防重复契约。 |
| WEB-NFR-REL-003 | 网络超时后不能直接假定操作失败，必须支持查询最终结果。 |
| WEB-NFR-REL-004 | 数据版本冲突应提示刷新、重新确认或放弃操作。 |
| WEB-NFR-REL-005 | 异步任务必须区分处理中、成功、失败、超时和人工处理。 |
| WEB-NFR-REL-006 | 全局错误不能导致整个应用白屏，应提供应用级和路由级错误边界。 |

## 5. 可访问性与可用性

| 编号 | 要求 |
|---|---|
| WEB-NFR-UX-001 | 不能只用颜色表达质量、设备或业务状态。 |
| WEB-NFR-UX-002 | 表单、按钮、对话框和通知应有明确文本和键盘可操作路径。 |
| WEB-NFR-UX-003 | 关键操作应显示影响对象、当前状态和执行后果。 |
| WEB-NFR-UX-004 | 删除、放行、驳回、人工接管等高影响操作需要二次确认。 |
| WEB-NFR-UX-005 | 工业工作台应优先展示待办、异常和下一步动作，而不是装饰性图表。 |

## 6. 可维护性

| 编号 | 要求 |
|---|---|
| WEB-NFR-MNT-001 | TypeScript 严格类型检查必须通过。 |
| WEB-NFR-MNT-002 | 应用不得反向依赖其他应用。 |
| WEB-NFR-MNT-003 | 共享包不得依赖应用私有代码。 |
| WEB-NFR-MNT-004 | API DTO 必须在 API 边界生成或映射，领域组件只接收 View Model。 |
| WEB-NFR-MNT-005 | 公共组件进入共享包前必须证明被多个应用或领域稳定复用。 |
| WEB-NFR-MNT-006 | 依赖版本必须由锁文件和 Workspace Catalog 管理。 |

## 7. 可观测性

| 编号 | 要求 |
|---|---|
| WEB-NFR-OBS-001 | 前端错误应记录应用、路由、版本、时间和关联 ID。 |
| WEB-NFR-OBS-002 | 请求应传播 correlation ID，并在错误提示中提供可用于排障的参考标识。 |
| WEB-NFR-OBS-003 | 不将用户 ID、批次号、订单号等高基数字段作为无限制指标标签。 |
| WEB-NFR-OBS-004 | Source Map 的生成、上传和访问必须受发布策略控制。 |
| WEB-NFR-OBS-005 | 关键用户流程应具备可追踪的开始、成功、失败和中断事件。 |

## 8. 兼容性

- 支持现代 Chromium 内核桌面浏览器。
- V1 以桌面工作台为主，不以手机浏览器替代 PDA。
- 分辨率和缩放适配范围应在原型与测试文档中明确。
- 不使用仅在开发机可用的浏览器扩展或本地代理作为生产前提。
