# ADR-002：数据表格与工具类样式增量升级

- 状态：已由 ADR-003 取代；仅保留历史决策记录
- 日期：2026-10-05
- 适用范围：`mom-web` PC 管理端
- 决策人：用户

## 背景与决策

用户验收认为 TDesign Table 与弹窗的呈现不符合整站视觉目标，决定引入 vxe-table 与 Tailwind CSS，并让新改造页面退出 TDesign。首个迁移对象是 IAM 用户管理页：表格使用 vxe-table；弹窗、输入与弹窗按钮使用同套 vxe-pc-ui 基础组件，语义结构与视觉细节结合 MOM Token 实现。其他存量 TDesign 页面仍运行，但不作为新页面默认方案；后续逐页迁移并完成视觉和交互验收后，才可移除全局 TDesign 依赖。Tailwind 用于页面结构与细节组合，MOM Semantic Token 仍是颜色、排版与空间的权威来源。

## 实施边界

- 锁定 `vxe-table@4.22.3`、`vxe-pc-ui@4.18.21`、`tailwindcss@4.3.3`、`@tailwindcss/vite@4.3.3`；vxe-pc-ui 是 vxe-table 的基础组件依赖，不是第二套表单方案。
- Tailwind 不加载 Preflight，避免重置 TDesign 和现有 MOM 基础样式；通过 `@theme inline` 映射已有 Semantic Token，不引入独立色板。
- 首个改造页保持后端服务端分页、权限、错误、写入与日期格式化语义；改变呈现层并增加列宽调整、固定操作列和可切换密度。弹窗必须保留焦点约束、Esc、滚动锁定、写入时禁关与关闭后焦点恢复。
- 导航和页面操作图标统一从 `@lucide/vue@1.52.0` 按需导入，使用其 ISC 许可；不再用无业务含义的导航数字或零散文本符号充当图标。
- IAM `UserPageParams` 当前无过滤字段；列表输入框只能明确标注并实现“当前页筛选”，不得伪称跨页搜索。完整服务端搜索须先确认字段、匹配规则、分页总数语义，再扩展后端契约。
- 用户列表保留“详情、编辑”高频行操作；重置密码、删除放在行操作列的“更多”弹出层中，仍需确认。经本 Slice 确认的用户启停是独立即时写入，入口位于表格状态列，不再放进编辑表单；此例外不得自动推广至其他业务状态。
- 用户创建默认启用，后续如需停用可在列表状态列操作；状态冲突或写入结果不明时先刷新核对，禁止乐观翻转和直接重复提交。
- 不启用前端排序、批量编辑、导出、虚拟滚动或客户端持久化列配置；这些功能必须有真实业务需求与数据契约后再实施。

## 取舍与风险

继续深度定制 TDesign Table 是依赖更少的备选方案，但不满足此次指定的表格改造目标。新增表格引擎会增加构建体积与双主题维护成本，因此按路由页面导入组件和样式；每次迁移须检查亮暗主题、键盘焦点、1024px 横向滚动、中文与英文、空态及服务端错误。Tailwind 与既有 CSS 并行时，禁止在页面直接散落 Primitive 色值，也不以工具类覆盖第三方组件内部结构。

## 回滚边界

IAM 用户页仍使用原有 `useUserManagement` 用例状态和 API。若表格交互验收不通过，可仅回退该页表格呈现层与 vxe 样式，服务端契约和写入流程不需变更。
