# MOM PC Web 视觉与设计系统

## 1. 视觉方向

| 维度 | 决策 |
|---|---|
| 产品类型 | 制造运营与管理工作台 |
| 核心关键词 | 专业、克制、精确、现代、可信、智能 |
| 信息密度 | 中高密度 |
| 主要形态 | 数据表格、树、复杂表单、状态流、关系视图 |
| 默认主题 | 亮色；同时提供暗色与跟随系统 |
| 科技感来源 | 精确网格、冷静蓝青强调色、实时状态、数据关联、克制动效 |
| 智能感来源 | 异常优先、上下文提示、影响范围、解释与建议下一步 |

科技感不等于装饰感。主界面以信息可读性为第一目标，仅在状态变化、关键指标、实时连接和关系追踪中使用强调视觉。

## 2. Token 架构

Token 分三层：

```text
Primitive Token（原始色阶、尺寸）
        ↓
Semantic Token（背景、文本、边框、状态、层级）
        ↓
Component Token（表格、表单、菜单、弹窗、图表）
```

- 页面只能消费 Semantic 或 Component Token；
- Primitive Token 不直接散落到业务页面；
- TDesign 主题变量集中映射到 MOM Semantic Token；
- 业务模块不得各自覆盖全局组件库变量。

## 3. 色彩系统

以下数值是 Web-P1 的实现基线；薄技术验证允许为满足对比度和 TDesign 映射做小幅调整，但必须回写本文。

| `color-border-default` | `#D5DEE4` | 默认边框 |
| `color-border-strong` | `#AEBCC6` | 强分隔 |
| `color-brand-primary` | `#126E82` | 主操作、选中态 |
| `color-brand-hover` | `#0E5C6D` | 主色悬停 |

### 3.3 语义色

| 语义 | 建议主色 | 规则 |
|---|---:|---|
| 成功/正常 | `#2E7D5B` | 必须配合文字或图标 |
| 警告/待处理 | `#A66512` | 不与普通强调色混用 |
| 错误/危险 | `#C23B3B` | 删除、失败、阻断 |
| 信息 | `#2F6FA3` | 中性通知与帮助 |
| 离线/未知 | `#6B7780` | 明确标注“未知/离线” |

图表色板与语义色分离；业务状态不得随意复用图表颜色。

## 4. 排版

### 4.1 字体

```text
UI Sans：Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif
Mono："JetBrains Mono", "SFMono-Regular", Consolas, monospace
```

不把远程字体作为首屏必要依赖。Mono 只用于编码、批次号、技术标识、数值对齐等场景。

### 4.2 字号阶梯

| Token | 大小/行高 | 用途 |
|---|---|---|
| `font-size-xs` | `12/20px` | 标签、次要元数据 |
| `font-size-sm` | `13/20px` | 紧凑表格、辅助操作 |
| `font-size-body` | `14/22px` | 默认正文、表单、表格 |
| `font-size-md` | `16/24px` | 区块标题、重要数值 |
| `font-size-lg` | `18/28px` | 页面次级标题 |
| `font-size-xl` | `24/32px` | 页面标题 |
| `font-size-display` | `32/40px` | 少量工作台关键指标 |

默认字重使用 400、500、600；避免整页粗体造成层级失真。

## 5. 空间、尺寸与层级

### 5.1 间距

采用 4px 基础网格：`4、8、12、16、20、24、32、40、48、64px`。

- 页面边距：桌面 24px，大屏 32px，1024px 宽度下 16px；
- 区块间距：24px；
- 卡片内边距：16px 或 20px；
- 表单字段纵向间距：16px；
- 内联操作间距：8px。

### 5.2 控件密度

| 模式 | 控件高度 | 使用范围 |
|---|---:|---|
| Compact | 28–30px | 超高密度辅助区域，谨慎使用 |
| Default | 32–36px | 表格筛选、常规表单和按钮 |
| Comfortable | 40px | 登录、关键表单、低频高风险操作 |

全局默认使用 32–36px，不允许不同模块擅自改变密度。

### 5.3 圆角与阴影

- 输入框、按钮：8px，主要动作可使用胶囊形；
- 卡片、面板：12px；
- 弹窗、抽屉：16px；
- 标签：4px 或胶囊形，按状态语义使用；
- 普通卡片主要依靠边框和背景分层，不普遍使用悬浮阴影；
- 阴影仅用于下拉、弹层、拖拽和需要脱离文档流的对象。

该圆角基线在 Web-P1-S04 根据整站“柔和、科技、智能”的方向上调；圆角只降低视觉冲突，不使用高饱和渐变或大面积发光制造伪科技感。

### 5.4 Z-Index

| 层级 | Token | 基线 |
|---|---|---:|
| 页面内容 | `z-content` | 0 |
| 吸顶/侧栏 | `z-sticky` | 100 |
| 下拉/气泡 | `z-popover` | 1000 |
| 遮罩/抽屉 | `z-overlay` | 2000 |
| 弹窗 | `z-modal` | 2100 |
| Toast/通知 | `z-notification` | 3000 |

最终值需与 TDesign 的层级体系集中映射，不在页面使用随机大数。

## 6. 组件视觉规则

### 6.1 表格

- 表头与主体使用轻微背景层级，不使用粗重网格线；
- 数量、金额、比例右对齐，编码和标识可使用等宽字体；
- 行操作优先保留 1–2 个高频项，其余进入“更多”；
- 固定列必须克制，避免窄屏只剩固定区；
- 列配置、密度和排序只有真实需求时才持久化；
- 空数据、筛选无结果、加载失败必须分别呈现。

### 6.2 表单

- 标签默认置于控件上方，密集查询条件可使用行内布局；
- 必填标识、说明、校验错误位置保持一致；
- 长表单按业务语义分区，不用纯视觉卡片无限切割；
- 保存、取消位置稳定，危险操作与保存区隔离；
- 版本冲突必须引导重新读取，不能静默覆盖。

### 6.3 卡片

卡片只用于形成真实信息分组，不把每个字段、指标或按钮都装入独立卡片。列表管理页优先使用连续表面与清晰分隔。

### 6.4 状态标签

状态标签由“文本 + 色彩 + 可选图标”组成。高风险状态不能只用浅色背景；需要足够的文本对比度。

### 6.5 图标

- 首选 TDesign Icons；
- 同一语义只保留一个图标；
- 装饰图标对屏幕阅读器隐藏；
- 图标按钮提供 `aria-label` 和 Tooltip；
- 不把 Emoji 当作生产界面图标体系。

## 7. 科技感与智能感落地

允许使用：

- 数据新鲜度、连接状态、事件时间和趋势变化；
- 细线网格、紧凑数值排版和清晰状态轨道；
- 关系高亮、路径追踪、异常聚焦和影响范围；
- 150–240ms 的状态过渡、列表更新和层级展开；
- 有真实依据的风险提示与建议下一步。

禁止使用：

- 无业务含义的扫描线、光晕、流光边框和 3D 地球；
- 为普通 CRUD 页面增加持续动画；
- 模拟“AI 正在思考”但没有真实任务；
- 将所有内容放入玻璃拟态卡片；
- 深色主题下牺牲表格、表单和状态对比度。

## 8. 动效

| Token | 时长 | 场景 |
|---|---:|---|
| `motion-fast` | 120ms | Hover、Focus、按压 |
| `motion-base` | 180ms | 菜单展开、状态切换 |
| `motion-slow` | 240ms | 抽屉、弹窗、页面局部进入 |

缓动优先使用标准 ease-out 进入、ease-in 退出。数据刷新不触发大面积位移动画。启用减少动画偏好时，只保留必要的透明度和即时状态变化。

## 9. 设计 QA

每个页面至少检查：

- 亮色、暗色、跟随系统；
- 1280px、1440px、1920px 和 1024px；
- 中文、英文长文本；
- 键盘焦点、弹窗焦点和图标按钮名称；
- Loading、Empty、No Result、Error、Forbidden；
- 浏览器缩放 200%；
- 状态色在常见色觉差异下仍有文字/形状辅助；
- `prefers-reduced-motion`。

## 10. Web-P1-S03 实现基线

样式按以下顺序装配：

```text
src/styles/primitives.css   原始色阶、尺寸、字体、圆角和动效参考值
        ↓
src/styles/semantic.css     亮暗主题、语义颜色、排版、间距和层级
        ↓
src/styles/components.css   布局尺寸、控件密度和 TDesign Token 映射
        ↓
src/styles/base.css         全局基础样式、焦点与减少动画
```

主题由 `src/shared/theme/theme.ts` 唯一管理：

- 偏好值仅允许 `light`、`dark`、`system`；未选择时默认 `light`；
- 本地键为 `mom.theme.preference`，只代表浏览器偏好，不属于 System 用户偏好或权限事实；
- `system` 通过 `prefers-color-scheme` 解析，并监听操作系统主题变化；
- `index.html` 在样式和 Vue 加载前应用同一键，避免首屏主题闪烁；
- localStorage 被浏览器策略禁用时，主题切换仍在当前标签页生效，只是不持久化；
- 页面不得直接写 `theme-mode`、读取主题键或自行监听系统主题。

当前共享页面容器为 `src/shared/components/PageContainer.vue`，只负责统一内容最大宽度，
不捆绑标题、面包屑或操作区。后续只有在这些结构出现稳定复用后才扩展组件职责。
