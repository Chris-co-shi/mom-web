## 1. 仓库职责

`mom-web` 只负责浏览器运行时：三应用 Client 配置、PKCE、内存 Token、Single Flight Refresh、`/api/iam/me`、路由/菜单/按钮体验控制、当前 Factory 偏好和 HTTP 错误恢复。

本仓库不定义后端用户、Token、Session、RBAC、Factory/Party Scope、Gateway 或业务服务最终授权语义。

## 4. S08：Web Auth Runtime

实现：

- `@mom/auth`。
- 三应用独立 `client_id`、Redirect URI 和环境配置。
- Authorization Code + PKCE S256 + OIDC。
- Access/Refresh Token 只存在内存。
- `sessionStorage` 一次性授权事务。
- Callback 校验和地址栏清理。
- 页面刷新后的顶层 PKCE 恢复。
- Single Flight Refresh。
- 每个业务请求最多自动重试一次。
- `/api/iam/me` 初始化和当前 Factory 重新校验。
- 401、403、409、429、5xx 统一处理。

验收：

- 三应用独立登录且不能混用 Client。
- user_type 与应用不匹配时安全拒绝。
- localStorage、IndexedDB、持久化 Pinia 和普通 Cookie 中不存在 Token。
- 并发 401 只产生一次 Refresh。
- 403 不触发 Refresh。
- 页面刷新能通过 IAM 登录状态快速恢复。

## 5. S09：MOM Admin 权限管理页面

实现：

- 用户管理。
- 用户角色分配。
- Factory Scope。
- Mobile Access。
- 角色与系统 Permission 配置。
- Permission 只读目录。
- Session 管理。
- 安全审计。
- OAuth Client 只读查看和可选受控启停。

前端不允许动态创建或修改 Permission Code，不允许删除系统角色，不允许删除最后一个有效 `PLATFORM_ADMIN`。

## 6. S10：Supplier Portal 与 Customer Portal

实现：

- `mom-supplier-web` 只允许 `SUPPLIER`。
- `mom-customer-web` 只允许 `CUSTOMER`。
- 固定 `party_id`，不提供主体切换器。
- Factory 仅在主体有效关系和授权子集中选择。
- 外部数据最小披露。
- 404 防枚举语义和安全错误展示。

## 7. S12：Web 安全 E2E

覆盖：

- PKCE、state、nonce、Redirect URI。
- Client/user_type 隔离。
- Token 过期、刷新、并发刷新、撤销和绝对 Session 到期。
- 页面刷新恢复、退出和 IAM SSO 状态。
- `/api/iam/me` 权限变化。
- 路由、菜单、按钮、403、404 和当前 Factory。
- Supplier/Customer Party 固定。
- 浏览器存储敏感信息扫描。
- 日志和错误提示敏感信息扫描。
