# V1 页面需求

## 1. 说明

本文档使用 `WEB-*` 编号记录 MOM Web V1 的页面和交互需求。页面实现必须关联用户流程、状态矩阵、原型、组件映射和 API 映射。

## 2. 通用能力

| 编号 | 需求 |
|---|---|
| WEB-COM-001 | 三套应用应分别提供登录入口、会话恢复、退出和重新认证处理。 |
| WEB-COM-002 | 所有业务请求必须通过 MOM Gateway。 |
| WEB-COM-003 | 页面应统一展示加载、空数据、无权限、网络失败和业务失败状态。 |
| WEB-COM-004 | 命令操作应防止重复提交，并展示明确的处理结果。 |
| WEB-COM-005 | 请求失败时应保留 correlation ID 或可供排障的错误参考标识。 |
| WEB-COM-006 | 用户只能看到其角色和数据范围允许的菜单、路由和操作。 |
| WEB-COM-007 | 前端隐藏操作不能替代服务端权限校验。 |
| WEB-COM-008 | 异步任务应展示当前状态、更新时间、失败原因和恢复动作。 |
| WEB-COM-009 | 关键页面应支持按工厂、业务状态和时间范围筛选。 |
| WEB-COM-010 | 所有时间展示必须明确业务时区，并避免前端自行改变业务日期语义。 |

## 3. MOM 管理端

### 3.1 运营工作台

| 编号 | 需求 |
|---|---|
| WEB-ADM-001 | 展示待处理到货、执行中工单、待放行批次、设备或集成异常等核心工作项。 |
| WEB-ADM-002 | 工作项应可按角色进入对应业务页面。 |
| WEB-ADM-003 | 工作台统计必须明确数据口径和更新时间。 |

### 3.2 供应商送货与来料

| 编号 | 需求 |
|---|---|
| WEB-ADM-010 | 支持查询供应商送货单、批次、容器和预计到货时间。 |
| WEB-ADM-011 | 展示送货单生命周期和异常状态。 |
| WEB-ADM-012 | 支持从送货单进入来料检验、收货和批次信息。 |

### 3.3 质量检验

| 编号 | 需求 |
|---|---|
| WEB-ADM-020 | 支持来料检验任务列表、详情和结果查看。 |
| WEB-ADM-021 | 未放行原料应明确显示不可用原因。 |
| WEB-ADM-022 | 支持成品检验、放行和不合格状态查看。 |
| WEB-ADM-023 | 质量操作应显示权限、当前状态和可执行动作。 |

### 3.4 库存与仓储

| 编号 | 需求 |
|---|---|
| WEB-ADM-030 | 展示库存的在库、预占、锁定、隔离和可用数量。 |
| WEB-ADM-031 | 支持查询库存流水和余额变化依据。 |
| WEB-ADM-032 | 支持查看 WCS 入库任务、运输状态和异常恢复。 |
| WEB-ADM-033 | 不得通过前端计算替代 WMS 权威可用量。 |

### 3.5 生产执行

| 编号 | 需求 |
|---|---|
| WEB-ADM-040 | 支持生产工单列表、详情和状态查询。 |
| WEB-ADM-041 | 展示 BOM、配方、工艺和质量标准版本快照。 |
| WEB-ADM-042 | 展示原料预占、领料、投料和实际消耗。 |
| WEB-ADM-043 | 展示 PCS 命令、步骤状态、超时和恢复信息。 |
| WEB-ADM-044 | 展示半成品和成品批次产出。 |

### 3.6 批次追溯

| 编号 | 需求 |
|---|---|
| WEB-ADM-050 | 支持从成品批次反查原料、生产过程和质量结果。 |
| WEB-ADM-051 | 支持从原料批次正查受影响成品、库存、发运和客户。 |
| WEB-ADM-052 | 谱系图必须支持拆分、合并、返工和降级关系。 |
| WEB-ADM-053 | 图形查询应同时提供可读列表或详情视图。 |
| WEB-ADM-054 | 支持模拟召回并展示影响范围。 |

### 3.7 集成与诊断

| 编号 | 需求 |
|---|---|
| WEB-ADM-060 | 支持查询外部接口调用、重试、补偿和对账状态。 |
| WEB-ADM-061 | 支持查询消息事件、重复处理和失败原因。 |
| WEB-ADM-062 | 支持显示 trace ID、correlation ID、event ID 和 command ID。 |
| WEB-ADM-063 | 限流或依赖故障应提供可理解的用户提示，而不是暴露底层堆栈。 |

## 4. 供应商门户

| 编号 | 需求 |
|---|---|
| WEB-SUP-001 | 支持创建和保存供应商送货单。 |
| WEB-SUP-002 | 支持维护物料批次、数量、包装和预计到货时间。 |
| WEB-SUP-003 | 支持查看送货、到货、抽样、检验、收货和入库状态。 |
| WEB-SUP-004 | 支持查看来料不合格信息和补充材料要求。 |
| WEB-SUP-005 | 供应商只能访问所属供应商的数据。 |
| WEB-SUP-006 | 重复提交送货单时应返回已有结果或明确冲突信息。 |

## 5. 客户门户

| 编号 | 需求 |
|---|---|
| WEB-CUS-001 | 支持查询客户订单与交付进度。 |
| WEB-CUS-002 | 支持查询发运单、物流状态和关联成品批次。 |
| WEB-CUS-003 | 支持下载授权范围内的 COA 等质量文件。 |
| WEB-CUS-004 | 支持创建客诉并上传必要说明。 |
| WEB-CUS-005 | 支持查看客诉处理、批次影响分析和召回进度。 |
| WEB-CUS-006 | 客户只能访问所属客户组织的数据。 |

## 6. 页面交付验收

每个页面至少满足：

- 需求编号已关联。
- 用户流程已评审。
- 原型图已入库。
- 页面状态矩阵完整。
- 组件映射明确。
- API、权限、数据范围和错误码已映射。
- 实现与原型的差异有记录。
- 关键操作具备测试和验收证据。
