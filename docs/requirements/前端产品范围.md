# 前端产品范围

## 1. 文档目的

本文档定义 `mom-web` 在 MOM V1 中负责的用户、应用、业务体验和设计资产边界。

## 2. 产品定位

`mom-web` 是 MOM 项目的浏览器端应用平台，面向内部运营、供应商协同和客户协同三类场景。它负责将 MES、WMS、QMS、Integration 和 Traceability 的业务能力组织成可理解、可执行、可恢复的用户任务。

前端不拥有业务权威数据，也不替代后端领域规则。

## 3. V1 应用范围

### 3.1 MOM 管理端

主要用户：

- 集团与工厂管理员。
- 计划员。
- 生产操作与管理人员。
- 仓库管理人员。
- 质量检验与质量管理人员。
- 设备与集成人员。

V1 范围：

- 统一登录与工作台。
- 供应商送货与到货查询。
- 来料检验、放行与不合格状态查看。
- 收货、库存、预占和领料查询。
- 生产工单、版本快照和执行状态。
- 成品检验与放行。
- WCS 入库和发运状态。
- 批次正反向追溯与模拟召回。
- 集成、消息、限流和链路诊断入口。

### 3.2 供应商门户

主要用户：供应商业务、物流和质量人员。

V1 范围：

- 送货单创建与查询。
- 预约和到货状态。
- 原料批次和包装信息。
- 来料检验结果。
- 不合格协同与补充材料。

### 3.3 客户门户

主要用户：客户采购、物流、质量和售后人员。

V1 范围：

- 订单与交付状态。
- 发运信息。
- COA 等质量文件。
- 客诉创建和处理进度。
- 受影响批次和召回通知。

## 4. 设计资产范围

`mom-web` 同时负责：

- 用户流程。
- 页面结构和导航。
- Web 原型图。
- 页面状态矩阵。
- 组件映射。
- API、权限和数据范围映射。
- 交互错误、异步进度、冲突和恢复路径。

## 5. 不属于本仓库

- Java 后端实现。
- 数据库表和迁移脚本。
- 权威库存与批次事实。
- PCS/WCS 状态机实现。
- PDA 与离线扫码能力。
- k3s、中间件和可观测性部署。
- ERP/SAP 模拟器。

## 6. V1 非范围

- 通用低代码页面生成器。
- 由数据库表自动生成业务页面。
- 完整移动端适配替代 `mom-mobile`。
- AI Agent 交互。
- 全量 APS、BI 或复杂报表设计器。
- 面向全部行业的万能 MOM 模板。

## 7. 成功标准

V1 Web 成功至少表现为：

1. 三应用独立构建和发布。
2. OAuth 登录、刷新、退出和无权限处理闭环。
3. VS-01 关键页面完成原型和状态设计。
4. Gateway API 调用具备统一错误和关联 ID。
5. 页面权限和数据范围与服务端契约一致。
6. 可从 Web 完成核心业务演示和追溯演示。
