# MOM Web 当前实现地图

本文件是稳定前端状态的唯一摘要。精确字段和行为以路由、API 模块、页面及测试为准；其他文档只引用本页。

## 技术与公共能力

| 范围 | 当前实现 |
|---|---|
| 框架 | Vue 3、TypeScript、Vite、Vue Router、Pinia |
| UI | Reka UI/shadcn-vue、Tailwind CSS 4、TanStack Table v9、MOM Token |
| 横切能力 | 登录会话、权限可见性、统一 HTTP Client、主题、i18n、格式化与错误分类 |
| 共享组件 | `MomManagementHeader`、`MomListSurface`、`MomDataTable`、`MomCrud*`、`MomModal`、`MomUnavailableState` |
| 质量门禁 | ESLint、vue-tsc、Vitest、Vite build；统一入口 `pnpm verify` |

## 模块

| 模块 | 页面范围 | API 前缀/权限 |
|---|---|---|
| Auth/IAM | 登录、账户、用户、角色、权限、权限资源与关系分配 | `/auth`、`auth:*` |
| System | 字典、支持 Locale、动态国际化管理；编码规则管理入口 | 平台配置 `/system`、`system:*`；编码规则 `/mdm/code-rules` 与 `/wms/code-rules`，分别使用 Owner 的 `*:code-rule:read/write` |
| MDM | 组织/仓储结构、物料/UOM、配方、工艺路线、生产版本、质量基础定义、一致性检查 | `/mdm`、`mdm:*` |
| WMS | 实时库存总览与明细、期初建账、冻结/解冻、同仓库库位移动；总览按物料名称或编码、仓库编码筛选 | `/wms`、`wms:inventory:*`、`wms:opening:*`；移动目标库位使用 MDM 读权限 |
| QMS | 当前无运行时业务页面 | 未来 Slice 决定 |

## 编码规则管理

- 正式入口 `/system/code-rules`，接入 MDM 与 WMS；菜单允许任一 Owner 的读取权限，具体读写请求使用所选 Owner 的权限。
- Catalog 来自 Owner 后端，复用 `CodeRuleDesigner`；支持草稿创建/保存、完整 definition 恢复、分页历史修订、发布、停用及从历史复制新修订。
- 使用修订 ID 操作目标、`ruleVersion` 保护并发；409、未知写入及响应损坏阻止直接重试，未保存切换要求显式丢弃。
- 详情按后端 Catalog 展示片段名称、参数与选项名称；原始 JSON 和内部身份/并发版本收起到技术信息。列表显示规则组成，历史模式隐藏普通筛选并提供返回入口。
- 缺失 Handler/Provider 或 Catalog 不可用时保留完整历史定义供查看；预览不分配正式编号。WMS 期初单创建由后端事务按 `wms.opening.document` 分配正式编号，发号失败则不创建草稿。列表优先显示使用场景、编码和说明；创建必填使用场景，草稿可保存规则级说明，各修订共享。旧数据明确提示用途未填写，不推断业务场景。
- 开发代理将 HTML 深链接交回 SPA，JSON API/SSE 保持 Gateway 原路径；生产托管也须区分页面导航与 API 请求。

## 质量定义迁移

- 检验特性、检验方法和质量标准页面位于 `src/modules/mdm/`。
- 路由归入 MDM 导航，使用 `mdm:quality-definition:read/write`。
- 请求通过 MDM API；业务动态文案使用 `mdm.*` Owner。
- `src/modules/qms` 不再承载质量定义 API、页面或路由。
- 检验执行、结果、判定与放行页面尚未实现，不得从质量定义页面推导为已有 QMS 能力。

## 事实入口

- 路由与菜单：`src/router/route-registry.ts`、`src/modules/*/routes.ts`。
- API 前缀：`src/shared/api/config.ts`、`vite.config.ts`。
- 权限与会话：`src/modules/auth/`。
- 共享页面模式：`src/shared/components/`、`src/shared/ui/`。
- 设计数值：`src/styles/primitives.css`、`semantic.css`、`components.css`。
