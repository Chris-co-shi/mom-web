# MOM Web 全局视觉基线 v1

> 状态：Draft / 视觉基础已进入代码；业务页面仍按后端契约逐步迁移。

![MOM Admin 用户管理视觉稿](../assets/mom-admin-visual-foundation-v1.png)

## 1. 设计目标

MOM Web 面向制造业中高密度业务页面。视觉语言应现代、稳定、清晰，避免传统后台的拥挤感，也避免展示型产品的大留白和重阴影。

## 2. 已确认的全局布局

| 项目 | 规则 |
|---|---|
| 顶部全局栏 | 横跨全屏，高度 56px，固定 |
| 左侧导航 | 顶部栏下方开始；展开 240px、收起 64px；用户主动收起 |
| 多页签栏 | 高度 40px，浅靛蓝灰背景，轻量圆角块 |
| 滚动 | 顶部栏、侧栏和页签固定，仅主内容区滚动 |
| 内容间距 | 1366px 为 16px；1440～1680px 为 20px；1920px 及以上为 24px |
| 页面宽度 | 表格、总览流式利用宽度；表单与详情限制阅读宽度 |
| 复杂页头 | 面包屑独占上行；标题与说明居左，主要操作居右；标题区透明平铺 |
| 字号 | 页面标题 24px，说明 14px |
| 基础网格 | 4px |

## 3. 视觉令牌

- 主色：Indigo `#4F46E5`；悬浮 `#4338CA`；按下 `#3730A3`。
- 页面背景：微暖灰 `#F6F5F3`。
- 内容表面：近白 `#FFFEFC`。
- 页签层：浅靛蓝灰 `#EEF0F8`。
- 选中底色：`#EEF2FF`。
- 卡片圆角 12px，控件与页签圆角 8px。
- 默认使用 1px 低对比边框；悬浮或层级提升时才出现轻阴影。
- 动效使用 140 / 180 / 220ms，默认 `cubic-bezier(0.2, 0, 0, 1)`，只表达状态变化，不做装饰性弹跳。

令牌代码位于 `packages/design-tokens`，应用通过 CSS 变量消费，避免在页面内重复声明颜色和布局尺寸。

## 4. 国际化、时区与计量单位边界

这三项是跨前端、Gateway、后端服务、数据模型和用户偏好的架构能力，不属于某个业务模块的局部搜索条件。

### 4.1 语言

首期语言为 `zh-CN` 和 `en-US`。顶部语言入口属于全局偏好入口。当前视觉代码只固定入口位置和样式，不把“只有文字替换”误报为已完成国际化。

### 4.2 日期、时间与时区

- 后端与数据库保存统一时间点，API 使用带明确语义的 ISO 8601 / Instant 契约。
- 用户账号保存 IANA 时区，例如 `Asia/Tokyo`；未保存时首次采用浏览器时区。
- 语言只改变日期时间的显示格式，不改变时间点和账号时区。
- 页面通过共享格式化层展示时间；普通业务筛选不重复出现“全局时区”设置。
- 只有业务语义本身要求时区的场景（例如工厂班次日界线、跨区调度）才在业务条件中显式选择业务时区。

### 4.3 数量、小数与计量单位

- 千分位、小数分隔符和数字外观跟随当前语言。
- 原始值、业务单位、允许精度和舍入规则由物料、工艺、质量规格或字段元数据定义。
- 不因语言从中文切换英文而自动将 kg 转 lb、℃ 转 ℉。
- 单位换算必须是显式业务能力，由统一换算服务和审计规则控制；前端不得各模块自行实现。
- 后端 API 应传递可计算的数值与稳定单位代码，前端共享格式化层负责本地化标签和展示。

## 5. 当前代码落地与非目标

本次落地：

- 全局设计令牌和 CSS 变量。
- MOM Admin 顶栏、侧栏、页签层、主内容滚动区。
- 响应式内容间距、透明标题区、容器边框与克制悬浮效果。
- `@mom/common-ui/Page` 公共页面容器，对齐 Vben 5.7.0 `Page` 的标题、说明、操作区与内容 Slots。
- MOM Admin 六个 IAM 管理页面统一消费公共 `Page`；Card、Table、Form、Modal 继续直接使用 Ant Design Vue。
- 用户管理页作为首个视觉示范页。

公共化边界：

- 不创建 MOM `AppShell`、`Sidebar`、`Tabbar`、`Breadcrumb`、`Preferences` 或 `LocaleSwitcher`。
- 上述能力由 Vben `BasicLayout`、Preferences 与 Locales 承担；当前 MOM Admin 手写壳层是尚未完成 Vben 布局接入前的应用私有过渡代码。
- Vben Workspace 包没有独立发布到 npm，源码迁移必须逐项登记，禁止复制完整演示应用。

本次不包含：

- 完整菜单图标体系。
- 真正的多页签路由缓存与跨设备恢复。
- 深色主题全部组件状态。
- 用户偏好后端接口。
- 完整 i18n 消息、时区格式化和单位换算实现。

这些能力必须在契约冻结后独立实施，不能通过静态按钮或页面局部状态伪装为完成。
