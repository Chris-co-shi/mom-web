## 4. S08 验收结果

Draft PR #4 Exact SHA `928093c4c4a973979242e8899cf54ede88417f4c` 已通过：

- `pnpm install --frozen-lockfile`；
- `pnpm validate`；
- `pnpm check:type`；
- `pnpm test`，真实执行 Auth/API Client 7 项测试；
- `pnpm build`，三个应用全部构建成功。

已确认：

- 端口固定为 5555、5556、5557；
- Client/user_type 矩阵分别为 Admin/INTERNAL、Supplier/SUPPLIER、Customer/CUSTOMER；
- Access、Refresh、ID Token 只存在内存；
- `sessionStorage` 只保存一次性 PKCE 事务并在成功或失败后删除；
- Callback 校验 state、nonce、RS256、issuer、audience、expiry 并清理地址栏；
- 401 使用 Single Flight，每个业务请求最多重试一次，403 不刷新；
- `/api/iam/me` 是完整权限上下文来源；
- 当前 Factory 偏好重新校验；
- Supplier/Customer 不提供 Party 切换。
