# MOM Web 实施路线

当前已实现能力见 [当前实现地图](当前实现地图.md)。本文件只描述下一阶段，不保存逐 Slice 日志。

## 当前基线

- 应用骨架、主题、i18n、HTTP Client、认证会话和权限可见性已经可复用。
- IAM、System 与 MDM 管理页面已进入真实代码。
- 质量基础定义属于 MDM；QMS 运行时页面尚未开始。

## 下一阶段原则

1. 由后端已确认的业务 Slice 驱动页面，不提前生成空模块。
2. 每个页面先确认 API、权限、分页、并发版本和失败语义。
3. 优先复用共享管理组件，不建立万能 CRUD 框架。
4. 真实联调、响应式、键盘、主题和长文案验收与自动化测试分开记录在 PR 中，不新增长期验证报告。

后续业务顺序由 `mom-platform/docs/plans/V1路线图.md` 和具体 Slice 决定。
