# Web-P2-S05 权限管理

## 边界与编码前自查

- 目标：在已验收的用户、角色管理页之后交付 Permission 目录，不提前实现赋权关系。
- 数据所有权：Auth 拥有 Permission 与 Role-Permission 关系；Web 仅经 Gateway 调用现有 API，不写数据库，不改变认证或 Token 语义。
- 接口：浏览器统一使用 `/auth/permissions/**`，开发代理内部对应 `/api/auth/permissions/**`；分页 `POST /search` 只发送空 `params`。创建 `code/name/description/enabled`，更新 `name/description/enabled/version`，状态写带 `version`，删除无版本条件。
- 复用：沿用 IAM 的 API/Model/Page 边界、统一 HTTP Client、权限守卫、VXE Table、`MomModal`、主题 Token、双语文案与加载遮罩。不建通用 CRUD 框架；同类目录页尚未超过项目规定的公共组件抽象阈值。
- 不做：角色赋权、用户分配角色、服务端尚不支持的关键词筛选、批量操作、Token 权限热更新、后端改造、新增依赖或改动既有用户/角色业务规则。

## DESIGN ISSUE

权限停用会从**后续登录**授权中排除该编码，但已签发 Token 的权限快照不会被撤销；误停用关键权限的影响较大。当前方案仍可实现：**YES**。状态列点击先打开 `MomModal`，展示编码、名称、现状和生效范围，确认后才调用带版本的状态接口。前端不按编码创造管理员豁免，最终授权仍由 Auth 控制。

## 实现与调用链

权限页面与弹窗 → `usePermissionManagement` → `permissions-api` → 统一 HTTP Client → Gateway `/auth/permissions/**` → Auth `PermissionController` → `PermissionApplication` → `mom_auth` Permission 表。

- 页面/菜单要求 `auth:permission:read`；创建、编辑、启停和删除入口及提交均要求 `auth:permission:write`。前端门禁只管体验，后端 `@PreAuthorize` 是授权边界。
- 目录按服务端 `code,id` 排序、分页；搜索明确只过滤已加载的当前页。编码只在创建时输入，后端允许最长 160 字符；ID 保持字符串，不展示技术主键。
- 状态与删除先读详情，再确认写入；更新和启停提交读取到的 `version`。引用中的权限删除由后端拒绝，Web 不模拟级联删除。
- 列表首次加载、刷新、翻页、每页数量调整和写后重读均有局部遮罩；保存期间弹窗遮罩、禁关且防重复提交。
- 409 冲突保留表单草稿并要求重读；结果未知阻止直接重发写入，列表读取成功后仍需操作者核对。成功写入与后续读取失败分别反馈。

## 验收证据与风险

`pnpm verify` 通过：Lint、TypeScript、21 个测试文件的 116 项测试与生产构建均通过；权限页定向测试覆盖 API 路径/字段、读写权限、分页乱序、详情失败、版本冲突、引用删除、未知写结果、状态二次确认、组件结构与加载遮罩。构建仍提示共享 VXE 弹窗资源超过 500 kB，这不是本 Slice 新引入的依赖。模拟 API 的组件测试不等于真实 Gateway/Auth 联调。本轮按用户要求不反复操作测试页面；真实写入和视觉确认待用户验收。

- A（验收前）：使用专用测试权限核对真实 CRUD、启停、引用拒绝、只读视图、亮暗主题及键盘操作；不要改动支撑管理员登录的既有权限编码。
- B（V1 已知边界）：删除没有版本条件；停用不回收既有 Token。多管理员并发删除与授权即时撤销不能由前端保证。
- C（当前过度设计）：通用权限树、动态菜单规则平台、跨服务权限自动发现和通用 CRUD 框架不属于本 Slice。
# 2026-10-05 页面布局修订

用户确认权限资源与其下权限采用左右主从：左侧为服务端分页及搜索的资源选择列，右侧仅展示当前资源的权限动作表格。资源列不是第二张 CRUD 表，资源详情、编辑、状态和删除放在右侧资源标题区域；权限动作沿用 VXE 表格、统一弹窗和原有授权边界。该布局是资源—权限父子关系的明确例外，不推广为所有 CRUD 页面模板。未改变 Auth API、数据所有权、权限编码或角色赋权语义。页面视觉、键盘和主题仍待用户人工验收。

资源数量增长后的导航策略：左栏以单行资源项替代大卡片，搜索框和服务端分页保持在滚动列表之外；每页最多 20 项，列表独立滚动。翻页和搜索仅改变左侧候选项，不自动切换右侧正在查看的资源；当前资源不在本页结果中时显示明确提示。仅首次进入或当前资源删除后自动选中可见首项。资源名称、编码和状态仍可识别，长文案在单行内截断并保留完整标题提示。
