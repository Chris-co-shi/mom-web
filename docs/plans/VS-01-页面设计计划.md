# VS-01：原料到成品页面设计计划

## 1. 目标

为以下业务闭环建立可进入实现的 Web 设计资产：

```text
供应商送货
→ 来料检验
→ 原料收货与入库
→ 生产工单与物料预占
→ PCS 生产执行
→ 成品检验放行
→ WCS 自动入库
→ 客户发运
→ 正反向追溯与模拟召回
```

## 2. 页面族

### 2.1 供应商门户

- 送货单列表。
- 创建/编辑送货单。
- 送货单详情。
- 来料检验状态。
- 不合格协同详情。

### 2.2 MOM 管理端：入厂

- 到货工作台。
- 送货单详情。
- 来料检验任务列表。
- 检验任务详情。
- 原料批次详情。
- 收货与入库结果。

### 2.3 MOM 管理端：生产

- 生产工作台。
- 工单列表。
- 工单详情。
- 版本快照详情。
- 物料预占与领料。
- PCS 执行步骤。
- 实际消耗和产出。
- 成品批次详情。

### 2.4 MOM 管理端：质量与仓储

- 成品检验任务。
- 成品放行详情。
- WCS 入库任务。
- 库存与库位详情。
- 发运详情。

### 2.5 MOM 管理端：追溯

- 追溯查询入口。
- 批次谱系图。
- 谱系列表和边详情。
- 影响分析。
- 模拟召回结果。

### 2.6 客户门户

- 订单列表与详情。
- 发运列表与详情。
- COA 文件列表。
- 客诉创建。
- 客诉详情和影响分析进度。

## 3. 设计交付批次

| 批次 | 页面族 | 主要目标 |
|---|---|---|
| D1 | 供应商送货与到货 | 验证门户、表单、重复提交和状态时间线 |
| D2 | 来料检验与收货 | 验证工作台、检验、质量状态和批次详情 |
| D3 | 工单与生产执行 | 验证复杂详情、版本快照、PCS 状态和异步更新 |
| D4 | 放行、WCS 与发运 | 验证跨域状态、任务恢复和客户可见数据 |
| D5 | 谱系与召回 | 验证图形、列表、筛选、聚合和影响分析 |

## 4. 每个页面的必备材料

- 关联需求编号。
- 用户角色和数据范围。
- 入口和前置条件。
- 主成功流程。
- 异常和恢复流程。
- 页面原型。
- 页面状态矩阵。
- 组件映射。
- API、权限、错误码和幂等映射。
- 可观测性字段。
- 测试与验收场景。

- 已预约。
- 已到货。
- 检验中。
- 部分接收。
- 已接收。
- 已拒收。
- 已取消。

### 5.2 工单

- 草稿。
- 已下达。
- 物料预占中/失败。
- 待执行。
- 执行中。
- 暂停。
- 恢复中。
- 已完成。
- 已取消。

### 5.3 PCS/WCS 任务

- 已创建。
- 已派发。
- 执行中。
- 超时。
- 阻塞。
- 恢复中。
- 人工接管。
- 已完成。

### 5.4 质量

- 待抽样。
- 检验中。
- 待审核。
- 已放行。
- 已拒绝。
- 隔离中。
- 处置中。

## 6. 原型要求

每个页面族至少提供：

- 列表/工作台。
- 详情。
- 表单或命令对话框。
- 加载、空、无权限和失败状态。
- 重复提交或版本冲突。
- 异步处理中和恢复。
- 窄屏或最小支持宽度说明。

## 7. 验收

设计批次只有在以下条件全部满足后才能进入实现：

- 业务、产品和架构边界无冲突。
- 页面状态与后端状态机一致。
- API 和权限映射有真实契约依据。
- 原型不使用尚未批准的业务规则。
- 异常和恢复路径完整。
- 组件复用和私有实现边界清晰。
