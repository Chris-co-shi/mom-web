# V1 页面路线图

## 1. 目标

在不提前堆叠业务 CRUD 的前提下，按技术骨架、入厂链路、生产链路、出厂与追溯链路四个阶段完成 MOM Web V1。

## 2. 阶段总览

| 阶段 | 目标 | 主要应用 | 状态 |
|---|---|---|---|
| Web Phase 01 | 三应用骨架、OAuth、Gateway Client、Access、设计交付和测试基础 | 全部 | 进行中 |
| Web Phase 02 | 供应商送货、来料检验、收货与库存 | 管理端、供应商门户 | 计划中 |
| Web Phase 03 | 工单、生产执行、PCS、成品检验放行 | 管理端 | 计划中 |
| Web Phase 04 | WCS 入库、发运、客户门户、追溯、召回和诊断 | 管理端、客户门户 | 计划中 |

## 3. Web Phase 01：技术与设计骨架

### 目标

- 三应用统一工程规则与独立发布边界。
- Authorization Code + PKCE 登录闭环。
- Gateway-only API Client。
- 权限、数据范围和路由契约。
- Design Token 与领域组件边界。
- 原型、状态、组件和 API 映射规范。
- 基础测试和 CI 门禁。

### 验收

- 三应用可独立启动和构建。
- 登录、刷新、退出、过期和无权限场景有设计与实现入口。
- 请求能够传播 correlation ID。
- 全局错误和路由错误不导致白屏。
- VS-01 页面清单和原型交付计划完成。

## 4. Web Phase 02：入厂链路

### 页面范围

供应商门户：

- 送货单列表与详情。
- 创建/编辑送货单。
- 批次和包装信息。
- 到货与检验状态。
- 不合格协同。

MOM 管理端：

- 到货工作台。
- 来料检验任务。
- 检验详情与结果。
- 收货与库存查看。
- 原料批次详情。

### 验收

- 可完成供应商送货到原料入库的 Web 演示。
- 未放行原料明确不可用。
- 重复提交和状态变化有恢复提示。

## 5. Web Phase 03：生产链路

### 页面范围

- 生产工作台。
- 工单列表与详情。
- 生产版本快照。
- 原料预占与领料。
- PCS 步骤与命令状态。
- 实际投料和消耗。
- 半成品与成品批次。
- 成品检验和放行。

### 验收

- 可展示工单从下达到成品放行的完整状态。
- 可定位 PCS 超时、失败与恢复。
- 可对比计划数量、预占数量和实际消耗。

## 6. Web Phase 04：出厂、追溯与诊断

### 页面范围

- WCS 入库任务与异常。
- 成品库存和发运。
- 客户门户订单、发运和 COA。
- 客诉和处理进度。
- 批次谱系图和列表。
- 正向/反向追溯。
- 模拟召回。
- Integration、消息和 Trace 诊断。

### 验收

- 可从原料追到客户。
- 可从成品反查原料和过程。
- 可展示拆分、合并、返工和降级。
- 可查询异步失败和关联 ID。

## 7. 阶段门禁

每阶段进入编码前必须完成：

- 需求编号。
- 用户流程。
- 页面清单。
- 页面状态矩阵。
- 原型图。
- 组件映射。
- API、权限、数据范围和错误码映射。

每阶段完成前必须具备：

- Type Check。
- Build。
- 关键组件或页面测试。
- 关键用户流程 E2E。
- 原型与实现差异记录。
- 可演示验收证据。
