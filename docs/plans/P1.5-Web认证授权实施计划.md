## 5. S08 Exact SHA 验收

阶段 Draft PR 的同一 Head SHA 必须通过：

- `pnpm install --frozen-lockfile`；
- `pnpm validate`；
- `pnpm check:type`；
- `pnpm test`；
- `pnpm build`。

同时复核：

- 三应用固定矩阵：`mom-admin-web/INTERNAL`、`mom-supplier-web/SUPPLIER`、`mom-customer-web/CUSTOMER`；
- Public Client 不发送 `client_secret`，Redirect URI 精确配置；
- localStorage、IndexedDB、持久化 Pinia 和普通 Cookie 不保存 Token；
- `sessionStorage` 只保存一次性 state、nonce、code_verifier、returnUrl 等必要授权事务，使用后立即删除；
- Callback 校验 state、nonce、RS256 签名、issuer、audience 和 expiry，并清理地址栏协议参数；
- 并发 401 只产生一次 Refresh，每个业务请求最多自动重试一次；403 永不刷新；
- 页面刷新重新执行顶层 PKCE，不使用 hidden iframe 或跨标签页 Token 同步；
- `/api/iam/me` 是完整权限上下文来源，Client/user_type 不匹配时安全拒绝进入应用；
- 当前 Factory 偏好必须重新校验；
- Supplier/Customer Party 固定，不提供主体切换器。
